# 消费行业研究工作台：基金经理快速使用说明

## 启动

双击 `consumer-research-workbench.exe`。程序会启动本机研究服务，并自动在默认浏览器打开 `http://127.0.0.1:8765/`。

如果页面已经打开，再次双击程序只会重新打开工作台，不会创建第二套数据库。

## 日常使用

1. 在“今日研究”查看昨天截止的全行业状态、监控事项和最新研究成果。
2. 在“行业地图”浏览完整 11 个消费研究领域。
3. 在“研究任务”搜索任务，填写研究问题和截止日期并提交。
4. 在“任务队列”查看校验、执行、受阻原因和报告入口。
5. 在“报告工作台”阅读报告、核对结论与证据、留下具名批注。
6. 在“数据与证据”查看数据新鲜度、覆盖缺口和商业授权状态。

## 使用边界

- 正式研究日期最晚只能截止到昨天。
- “研究包已就绪”不等于数据已经全部回填。
- 系统不接入或推断基金持仓，不自动交易，不自动对外发布。
- Agent 完成生成并通过内置质量检查后，报告会直接展示，不需要任何内外部部门或人员审核。

## 无法打开页面

先确认程序仍在运行，再刷新页面。若端口被其他程序占用或数据库损坏，请联系基金公司信息技术管理员，不要删除本机 `data` 目录；其中保存任务、批注和报告状态。
