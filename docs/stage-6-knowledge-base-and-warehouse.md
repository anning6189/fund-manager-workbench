# 阶段六：消费行业知识库与数据仓库

版本：1.0.0  
验收日期：2026-08-13  
适用范围：面向公募基金经理的全消费行业研究 Agent；不包含基金持仓、组合暴露和仓位推断。

## 1. 验收结论

阶段六参考知识基础设施已经实现并通过端到端验收，判定为：

`accept_stage6_reference_knowledge_infrastructure_with_incremental_population_boundary`

完成含义：知识库、主数据、文档切片、证据、时序指标、历史版本、增量游标、新鲜度监控和隔离区已经有可运行实现；阶段三至五的规则不再只是设计文档。

边界：不宣称全市场消费公司、品牌、产品、SKU和历史文档已一次性回填完成。数据回填是受来源许可、更新频率和人工审核约束的持续任务。当前正式库使用经过验证的美的集团、格力电器年报样例建立闭环。

## 2. 已落地的四个模块

### 2.1 消费行业主数据

存储并支持历史时点查询：

- 法人、发行人、证券、品牌、品类、SKU、渠道、地域、客群、场景和价值链节点；
- 实体别名、外部标识和证券代码；
- 公司—发行人—证券、公司—品牌、品牌—品类等有向关系；
- 87个全消费分类节点和带有效期的实体分类；
- `valid_from/valid_to`、`observed_at`和人工审核状态。

正式种子数据包含10个实体、4个别名、2个证券标识、10条关系和2条行业分类，用于验证完整闭环，不代表全市场覆盖率。

### 2.2 文档知识库

已经实现：

- 文档身份、来源、URL、发布时间、可得时间、版本、许可、访问等级和SHA-256；
- 按页、章节和表格生成文档切片；
- 文档—实体绑定；
- 切片—证据—指标三层回链；
- SQLite FTS5全文检索和截止时点过滤；
- PDF或UTF-8文本生成标准摄取包的工具。

正式样例库含2份官方年报、4个页级切片和4条A级证据。查询经营现金流可返回年报名称、原文链接和PDF页码。

### 2.3 指标时序仓库

已经载入阶段四全部99项指标定义，并支持：

- 数值、单位、期间、业务时点、发布日期和可得时间；
- 公司财务的报表范围、并表范围、会计准则、币种、单位比例和期间类型；
- 原始值、供应商派生、Agent计算、估算和重述状态；
- 修订值新增版本而不覆盖历史记录；
- 按研究截止时间选择当时可得的最新版本；
- 指标反查证据、文档、切片和定位。

正式样例库含12项年报财务观测，用于证明跨公司、跨期间和证据回链能力。

### 2.4 增量更新和质量监控

已经建立22条来源—数据流刷新计划，覆盖阶段五注册的全部20个来源：

- 行情、财务、公告、宏观、政策、行业发布、研报、新闻、企业风险和主数据；
- 每条流保存游标、水位、上次成功时间、下次到期时间和新鲜度；
- 标准化摄取包放入 `data/normalized/inbox` 后可批量原子导入；
- 重复包幂等忽略；
- 失败包整体回滚并进入 `data/quarantine`；
- 基金持仓、许可不明、错误实体、未注册指标和不可定位证据被阻断；
- Gildata相关数据在合同确认前只能进入原始许可闸门，不能进入正式研究层。

## 3. 数据分层和本地实现

- `data/raw/documents`：不可变原始文档对象。
- `data/normalized/inbox`：等待准入的统一JSON摄取包。
- `data/curated/consumer-research.db`：通过准入门的可查询SQLite/FTS5知识库。
- `data/quarantine`：阻断记录和逐条问题报告。

SQLite是可运行参考实现，适合当前开发和验收。生产部署可替换为PostgreSQL、对象存储和经许可的向量索引；统一摄取包与历史时点语义保持不变。

## 4. 查询能力

命令行运行时支持：

- `resolve-entity`：按规范名、别名或外部标识消歧实体；
- `query-metric`：按实体、指标、期间和截止时点查询结构化数据；
- `search`：按关键词、实体和截止时点检索文档切片；
- `trace`：从证据ID反查原文、定位及其支持的全部观测；
- `refresh-plan`：生成需要执行的来源增量任务和许可状态；
- `freshness`：计算数据流新鲜度；
- `status`：输出表规模、全文索引、外键和数据库完整性。

## 7. 当前人口覆盖与生产边界

阶段六完成的是“数据资产底座可运行”，不是“全量数据已回填”：

- 目前正式库是闭环种子规模，不适合据此宣称消费公司全覆盖。
- 22条刷新流中，除种子财务流外尚未执行首轮全量或增量同步；美的/格力样例财务水位相对当前时间为陈旧状态，系统已正确标为`stale`。
- Gildata 8条数据流因合同和内部使用条款待确认，保持`raw_license_gate`。
- 商业渠道、消费者面板、同店、客流、售罄和另类数据未采购。
- 本地已提供全文检索；外部向量索引只有在许可、隐私和模型服务审批后才能启用。

阶段七可以直接使用本阶段的实体、指标、时点和证据查询接口，建设市场空间、竞争格局、经营拆分、财务预测和估值计算引擎。
