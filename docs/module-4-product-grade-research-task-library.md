# 模块四：研究任务库的全面产品化

## 产品结构

任务库由四层组成：10 个标准研究模板、110 个“行业×模板”产品、用户提交的点时研究任务，以及阶段八可审计工作流运行。产品面向公募基金经理、研究员、研究运营和研究复核角色。

十类产品包括行业全景、景气跟踪、公司深度、公司比较、财报点评、事件政策影响、竞争格局、市场规模、估值预期差、风险催化监控。每个产品都有参数合同、输出章节、指标清单、数据路由、质量门、标签、预估耗时和数据就绪状态。

## 已实现

- 110 个内部任务产品与 10 个模板的正式目录。
- 关键词、行业、类别和模板筛选，以及行业、模板、类别和数据就绪度 facets。
- 产品详情、收藏、系统视图和使用行为审计。
- 四角色权限；基金经理可查看、搜索、收藏和提交，但不能管理队列或修改目录。
- 命名用户提交、参数验证、去重、优先级、队列和任务状态机。
- 编译为阶段八工作流请求，运行结果停在人类复核闸门。
- 产品语义版本、内容哈希、更新草稿、命名研究复核员批准和发布审计。
- JSON 与 Markdown 产品目录。

## 产品边界

- 110 个产品均为 `internal_active`，但数据就绪状态仍为 `ready_with_data_gaps`。
- “产品可用”不等于“底层数据已经完整”。
- 新版本上线需要命名研究复核员，Agent 无权自批。
- 研究输出仍须阶段八人类发布闸门。
- 不接入或推断基金持仓和仓位，不自动生成交易指令。
