# 模块五：基金经理使用界面

## 1. 完成结论

模块五已经实现为可运行的本机网页产品，不再是 Canvas 原型。基金经理通过浏览器完成全消费行业状态查看、任务发起、任务跟踪、报告审阅、证据追溯与具名批注；本机服务直接使用阶段六至阶段八以及模块一至模块四的真实数据库与工作流。

产品默认绑定 `127.0.0.1:8765`，不对局域网或公网开放。开发环境可由启动脚本一键运行；正式交付路径已经准备独立可执行文件和 Windows 安装器配置，使基金经理安装后不需要 Python、Node.js、数据库工具或命令行。

## 2. 页面与功能

### 今日研究

- 默认正式研究截止到前一日 23:59:59（Asia/Shanghai）。
- 展示 11 个消费领域、110 个研究任务、监控事项、研究建议和最新内部研究成果。
- 数据状态与行业判断分开：覆盖缺口不能被误读成景气判断。

### 行业地图

- 完整覆盖 11 个消费研究领域，不收窄到单一子行业。
- 展示 A/H 市场覆盖、证券数、指标数、数据流、周期驱动与研究命题。
- 显式区分“研究包 ready”和“数据已回填”。

### 研究任务库

- 搜索、领域筛选、任务类型筛选和个人收藏。
- 110 个任务产品沿用模块四真实任务库。
- 提交必须包含具名用户、研究问题、截止日期与市场。
- 公司类任务可以从阶段六实体库选择研究对象。
- 正式截止日期不能晚于昨天；基金持仓和仓位字段被拒绝。

### 任务队列

- 任务、状态、优先级、截止时间和错误原因持久化到 SQLite。
- 明确区分排队、校验、执行、完成、受阻和失败；没有等待审核状态。
- 用户提交后才允许启动工作流；监控建议不会自动执行。

### 报告工作台

- 读取阶段八生成的 Markdown 报告。
- 展示结构化结论、内容标签、重要性、置信度、计算公式与输入。
- 每条结论可以回到支持证据或反证、来源、定位符和可得时间。
- 报告生成完成后直接展示；支持具名批注，但不设置批准、复核或审核按钮。

### 数据与证据

- 展示数据新鲜度、22 个行业—市场覆盖单元、商业授权状态和生产快照。
- 授权 pending、数据 stale、尚未开始和未回填均显式显示。
- Gildata 等商业源在授权未确认时不被标记为正式可用。

## 3. 本机安全与权限

- 服务只接受 `localhost` / `127.0.0.1` Host，默认不暴露到网络。
- 写操作要求每次启动随机生成的页面会话令牌。
- Content Security Policy、禁止页面嵌入、无缓存和 MIME 防嗅探均已开启。
- 审计日志记录具名用户、角色、动作、对象、结果和时间。
- 基金经理只能查看自己的任务；研究运营可管理队列；报告不需要任何部门或人员批准。
- 不接入基金持仓，不推断仓位，不自动交易，不自动对外发布。

## 4. 交付方式

### 当前开发工作区

运行 `tools/Start-FundManagerWorkbench.ps1` 可启动本机服务并自动打开浏览器。服务地址为 `http://127.0.0.1:8765/`。

### 基金经理电脑正式交付

1. 使用 `tools/Build-FundManagerWorkbenchPackage.ps1` 构建独立程序。
2. PyInstaller 将 Python 运行时、网页资源、Agent 引擎与所需规范打入可执行文件。
3. Inno Setup 脚本生成 Windows 一键安装程序和桌面快捷方式。
4. 安装器首次部署数据库，后续升级不覆盖基金经理的本机任务、报告与设置。
5. 基金经理双击桌面图标，服务启动并自动打开浏览器。

正式进入基金公司前，还需配置身份目录、商业数据凭证、模型凭证、终端加密、备份策略和软件签名。这些属于部署与数据接入条件，不是研究内容的审核流程。

## 5. 已知数据现实

界面已经实现并接入真实项目数据，但底层数据生产状态仍是部分完成：公开数据存在待回填流，商业源存在授权门禁，港股证券池尚未正式填充。界面会如实显示这些状态，因此“模块五完成”表示产品界面和本机交付链路完成，不表示所有外部数据许可和全量回填已经完成。
