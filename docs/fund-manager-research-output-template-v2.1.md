# 公募基金经理版行研输出模板 v2.1

适用：消费行业研究、公司横向比较和综合小测。模板只规定阅读结构，不改变证据准入、时点控制和决策边界。

## 0. 研究口径

- 截止时点、研究对象和行业边界。
- 币种、单位、会计准则、报告期及可比性。
- 未提供估值阈值、投资期限和风险预算时，不输出买卖建议或单一赢家。

## 1. 执行摘要

只回答四件事：行业处于什么阶段、两家公司最核心的差异、市场近期在交易什么、当前不能下什么结论。控制在四组要点内。

## 2. 行业环境与景气判断

先列官方已证事实，再列 Agent 推断，最后写明推断边界。样本公司的高增长不得直接外推为整个行业增速。

## 3. 公司横向比较看板

一张表集中展示两家公司同期间的收入、增速、毛利率、法定利润、经营现金流、库存、海外收入及占比、门店和关键 IP／品牌指标。相同维度必须在同一行，不拆成两家公司各自的数字清单。

表后只保留必要的会计口径和商业模式差异说明。

## 4. 公司深挖

两家公司严格使用相同子结构：

1. 商业模式与核心能力。
2. 增长驱动与最新经营变化。
3. 盈利和现金流质量。
4. 当前最需要验证的问题。

## 5. 行情、公告与预期变化

- 行情使用一张横向表，列示截止日价格、当日表现、成交和标准化区间收益率。
- 只保留可能改变经营判断的重要公告；例行治理事项降级。
- 机构研报单列为第三方观点，不与公司事实混写。

## 6. 风险与反证

按公司分别列示，每项包含“风险事实—影响路径—反方证据／尚不能确认的事项—后续指标”。风险数据库无返回只代表未取得合格记录，不代表不存在风险。

## 7. 最终结论与跟踪清单

给出按维度的有限结论，并列出下一次财报或高频跟踪需要验证的指标。需要基金经理判断的估值、赔率和风险预算单独标记。

## 8. 证据索引

按主题列第一来源、日期、原文定位、交叉验证和证据等级。长链接不在正文反复出现。

## 9. 测试运行附录

仅在测试或用户明确要求时显示，且必须置于研究正文之后：

- 核心数据就绪、完整检索完成、答案准备完成时间。
- 调用完成状态和实际字段完整性分开记录。
- 缓存回退、空结果、截断和计时器异常明确披露。
- 本附录不参与研究结论，也不得插入公司分析段落。
