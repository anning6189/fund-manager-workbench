# 消费行业研究工作台（Consumer Research Workbench）

一个面向**消费行业研究分析师**的本机 Web 工作台。  
项目目标是把研究能力做成“可直接打开即用”的应用：从数据采集、研究产出、任务与报告管理，到晨报、研报库、风险监控、模型问答、Token 用量展示与数据源状态，均在一个网页界面中完成闭环。

> 说明：当前项目同时具备本机开发模式与可对外发布的基础能力（需按部署说明配置 Nginx/HTTPS/防火墙）。

---

## 一、项目定位

- 作用对象：研究员、投研运营、基金经理  
- 核心价值：
  - 每日自动生成消费行业晨报与重点研究提示
  - 研报/公告/行业数据/政策/企业风险统一入库与追踪
  - 一站式查看数据源新鲜度与质量状态
  - 支持“问题驱动”AI问答（`/api/ask`）
  - 输出可追溯证据链（来源、发布时间、证据等级）

---

## 二、核心功能

- 今日简报（today）
  - 大盘观察、行业焦点、风险提醒、重点推荐
- 研报库（library）
  - 聚合研报元数据，支持按日期筛选与详情查看
- Token 用量（usage）
  - 历史用量/今日用量统计
- 数据来源（data）
  - 数据源新鲜度、状态、失败项、同步进度可视化
- AI 研报助手（ask）
  - 会话内提交问题，自动返回研究解释与上下文依据
- 任务与报告（reports）
  - 任务库、岗位化任务、报表与批注
- 收藏与告警
  - 任务收藏、告警标记与处理

---

## 三、技术栈

- Python 后端：原生 `http.server`（单文件服务）
- 数据库：SQLite（`data/curated/consumer-research.db`
