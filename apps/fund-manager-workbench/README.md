# 消费行业研究工作台

面向公募基金经理的本机网页式研究界面。服务默认监听 `127.0.0.1:8765` 用于本机体验，也支持通过 `--host 0.0.0.0`、`--deployment-mode internal_network` 与 `--allow-hosts` 进行公网演示部署。

## 使用方式

开发环境使用项目根目录的 `tools/Start-FundManagerWorkbench.ps1` 启动。正式交付包安装后，基金经理双击桌面“消费行业研究工作台”即可使用，不需要命令行或开发环境。

## 页面

- 今日简讯：首页集中展示国内宏观、消费行业概况和 6—8 条当日/前一日重点提示；每条提示可打开详情、数据状态与来源链路，已生成的相关行研报告可直接打开。
- 报告工作台：报告正文、结论—证据链、反证与批注。
- 数据与证据：新鲜度、市场覆盖、商业授权与生产快照状态。

## 固定安全边界

- 不接入或推断基金持仓与仓位。
- 不生成自动交易指令。
- 不自动对外发布报告。
- 商业授权、数据缺失与过期状态必须显式展示。
- 默认只允许本机回环访问；公网演示时可通过 `--host 0.0.0.0` 与 `--allow-hosts` 放行指定 Host，写操作仍要求页面会话令牌。

## 正式交付

`tools/Build-FundManagerWorkbenchPackage.ps1` 使用 PyInstaller 生成不依赖本机 Python 的独立程序；安装器脚本位于 `installer/ConsumerResearchWorkbench.iss`。正式交付前应替换对话中曾暴露的数据源令牌，并由基金公司的信息技术与合规部门确认商业数据授权。
